A short, 6-slide, ready-to-post LinkedIn carousel comparing SQL and NoSQL databases. Slides are square (1080x1080) so they work as a native LinkedIn "document" carousel post.

## How to post

1. Combine the 6 PNGs into a single PDF, in order (e.g. drag them into Canva/Preview/Keynote, or run `img2pdf slides/*.png -o sql-vs-nosql.pdf`).
2. On LinkedIn, start a new post and choose **Add a document**, then upload the PDF. LinkedIn will render it as a swipeable carousel.
3. Use the caption below (or your own).
