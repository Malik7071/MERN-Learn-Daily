# SQL vs NoSQL — LinkedIn Carousel

A short, attractive 8-slide carousel comparing SQL and NoSQL databases,
designed for a LinkedIn **document post**.

## Slides

1. Cover — SQL vs NoSQL
2. What is SQL?
3. What is NoSQL?
4. Key differences (table)
5. Same query, two styles (code)
6. When to use what
7. The takeaway
8. Call to action / follow

Each slide is a **1080 × 1080** square (LinkedIn's recommended carousel size).

## How to publish

1. Open `index.html` in **Google Chrome**.
2. Press **Ctrl/Cmd + P** to print.
3. Set **Destination → Save as PDF**.
4. Set **Margins → None** and enable **Background graphics**.
5. If available, set a **custom paper size of 1080 × 1080 px** (or use “Square”).
6. Save the PDF and upload it on LinkedIn via **Create post → Add a document**.
