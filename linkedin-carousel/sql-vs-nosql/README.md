# SQL vs NoSQL — LinkedIn Carousel

Short, swipeable 7-slide carousel comparing SQL and NoSQL for LinkedIn.

## Preview

Open `index.html` in a browser:

- Arrow keys or buttons to navigate
- Drag / swipe on the slide
- Click dots to jump

## Post to LinkedIn

1. Open `index.html`
2. **Print** → **Save as PDF** (include background graphics)
3. Upload the PDF as a LinkedIn document post

Slides are sized for a **1080×1350** portrait carousel.

## Slides

1. Cover — SQL vs NoSQL  
2. What SQL is  
3. What NoSQL is  
4. Side-by-side shape of data  
5. When to use SQL  
6. When to use NoSQL  
7. Bottom line + CTA
